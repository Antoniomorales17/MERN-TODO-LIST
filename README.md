## Descripción

Esta es una aplicación de ToDo List desarrollada con la arquitectura MERN (MongoDB, Express, React, Node.js). La aplicación permite a los usuarios:

- Crear, editar y eliminar tareas.
- Autenticarse en la aplicación con un sistema de inicio de sesión y registro.
- Gestionar las tareas asociadas a cada usuario autenticado.
- Disfrutar de una interfaz sencilla y funcional, estilizada con **TailwindCSS**.

## Características

- **Autenticación de Usuarios**: Registro, inicio de sesión y protección de rutas.
- **Gestión de Tareas**: Los usuarios pueden gestionar sus propias tareas. Estas se almacenan en MongoDB y están vinculadas al usuario correspondiente.
- **Estilos con TailwindCSS**: La interfaz se ha diseñado utilizando TailwindCSS para garantizar un estilo moderno y responsivo.
- **Backend en Node.js y Express**: El backend maneja todas las operaciones de CRUD, autenticación de usuario y gestión de sesiones.
- **Base de Datos en MongoDB**: MongoDB se utiliza como base de datos para almacenar usuarios y tareas.

## Tecnologías

### Frontend

- **React.js**: Librería de JavaScript para construir interfaces de usuario.
- **TailwindCSS**: Framework CSS para un diseño rápido y responsivo.

### Backend

- **Node.js**: Entorno de ejecución para construir el servidor.
- **Express.js**: Framework minimalista de backend para Node.js.
- **MongoDB**: Base de datos NoSQL para almacenar usuarios y tareas.
- **Mongoose**: ODM para MongoDB, utilizado para interactuar con la base de datos.
- **JWT (JSON Web Token)**: Para la autenticación de usuarios.
